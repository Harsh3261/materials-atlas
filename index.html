Equivalents — near is not identical

42CrMo (GB/T 3077) vs AISI 4140: NEAR — NOT INTERCHANGEABLE same Cr-Mo idea, different windows — 42CrMo Mn is 0.50–0.80%, 4140 Mn is 0.75–1.00%. A heat can pass one and fail the other on manganese alone. And the mechanical bases differ entirely: GB/T 3077 publishes Q&T reference-bar minimums; SAE J404 publishes no mechanicals at all.

40Cr vs AISI 5140: 40Cr's Cr window is 0.80–1.10% vs 5140's 0.70–0.90% — a 40Cr heat at 1.05% Cr is out of 5140 spec.

304 (ASTM A240) vs 1.4301 (EN 10088): the EN minimum Rp0.2 (230 MPa, cold-rolled strip) is higher than A240's 205 MPa, and the chemistry windows differ slightly. Dual-certified material exists precisely because neither standard contains the other.

E355 / ST52.3 / “1026-class” honed tube: three different documents (EN 10305-1, withdrawn DIN 2391, ASTM A519) with three different property bases — spec minimums by delivery condition, legacy minimums, and typicals. Same barrel application, not the same guarantee.

20CrMo's AISI cross is genuinely disputed (4120 vs 4118-family appear in different sources), so the atlas shows it as approximate. C36000 vs CW603N is the standard free-cutting-brass pair, but Pb windows and temper designations differ — a cert must name the system it certifies to.

Substitution rule: a near-equivalent may be proposed by a supplier; it is qualified only when chemistry (all restricted elements), condition, form/thickness band, and mechanical basis are each checked against the specified standard — or the substitution is formally approved as a deviation.

Carbon equivalent — weldability in one number

CE (IIW) = C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15

Enter a heat's chemistry (leave unused elements blank). Bands are guidance from standard welding practice (EN 1011 / AWS), not a specification: ≤ 0.40 generally weldable without special measures · 0.40–0.60 preheat likely · > 0.60 high hardenability — procedure-qualification territory.

Heat treatment — the condition is the material

Anneal — soften, improve machinability, relieve stress; the normal supply state for 4130/4140 bar before machining. Normalize — grain refinement and uniform properties (compare the A519 normalized rows against cold-worked). Quench — form martensite; the medium matters (the sourced rows show 4130 water-quenched, 4140/4340 oil-quenched). Temper — trade hardness for toughness. Carburize — hard case, tough core: 8620 and 20CrMo core properties are not case properties. Age — precipitation hardening: 17-4 PH H900, aluminium T6.

Hotter temper → softer, tougher. All three Q&T grades in the atlas (4130, 4140, 4340) show the same trend in the same source table. That is why a Q&T row without a tempering temperature is not a condition at all.

Flame-cut plate — the edge is no longer the grade you bought

Oxy-fuel cutting leaves a heat-affected zone: a thin hardened, sometimes micro-cracked edge layer on hardenable grades — and a softened band in Q&T plate (A514 class), where the cut heat over-tempers the edge. Higher carbon equivalent → deeper HAZ hardening and crack risk; thicker plate self-quenches the cut edge faster → harder HAZ. Check the PO/drawing for edge-condition requirements (grind or machine back the HAZ for fatigue or weld prep), and never certify a flame-cut edge's hardness as the plate's hardness.

The E355 lesson

EN 10305-1 delivery condition changes everything: +N (normalized) guarantees ReH ≥ 355 MPa, but +SR (stress relieved — the workhorse honed-barrel condition) guarantees ≥ 450 MPa. Online datasheets almost always quote the +N number and understate the steel by ~25%. Always match the cert's delivery condition to the row before comparing.

Which standard can actually give you a number?

The most useful qualification skill is knowing which documents cannot. SAE J403/J404 set chemistry only — no strength values exist in them. ASTM A519's mechanical table is headed “typical.” A GB/T 3077 mechanical value exists only for the standard's own reference-bar heat treatment.

What “qualified” looks like

Every box ticked: PO/callout naming standard + grade + condition + form; an EN 10204 3.1 / MTR with heat-matched actual chemistry and mechanicals; test methods and yield basis named; values clearing the SPEC MIN row for the delivered thickness band; and, for substitutions, a written deviation approval referencing the element-by-element and condition-by-condition comparison.

Data status key: SPEC MIN = guaranteed minimum (or specified range) from the governing standard's published table · TYPICAL = published average, not a guarantee, never for acceptance · MANUFACTURER = the maker's own published data. Bar-steel typicals carry their publisher's own warning: mill-lab averages on 1-in bars, a guide only — not a basis for acceptance or rejection. Section size matters throughout: GB/T 3077 minimums are 25 mm reference-bar values (15 mm for 20Mn2); Q&T properties fall off in heavy sections.

Below a spec minimum is a rejection. Below a typical is just a Tuesday.
